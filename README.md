# opennhrp-agent

Small C management agent for `opennhrp-manager`. It keeps the existing
Manager WebSocket protocol while replacing the Go agent.

## Requirements

- Linux
- C11 compiler
- OpenSSL 1.1.1 or newer

No JSON or WebSocket library is required.

## Build and test

```sh
make
make test  # requires Python 3 for local protocol regression tests
```

The executable is written to `build/opennhrp-agent`.

## Debian package

Install the build dependencies and build using standard Debian tooling:

```sh
sudo apt install build-essential debhelper libssl-dev
make deb
# Equivalent: dpkg-buildpackage -b -us -uc
```

Packages and build metadata are written to the parent directory. The package
version comes from `debian/changelog`; runtime library dependencies are
generated by `dpkg-shlibdeps`. Build on the target Debian/Ubuntu release to
use its runtime libraries.

The package installs `/etc/opennhrp-agent/agent.env` as a preserved configuration
file, readable only by root. Edit its connection settings after installation,
then start the service explicitly:

```sh
sudo systemctl enable --now opennhrp-agent
```

The package does not automatically enable or start the service.

## Run

```sh
opennhrp-agent \
  --server wss://manager.example.com/api/agent/ws \
  --node-id hub-1 \
  --node-type hub \
  --token replace-me
```

Options can also come from `SERVER`, `NODE_ID`, `NODE_TYPE`, and `TOKEN`.
Runtime paths use the same environment variables as the Go agent:
`OPENNHRP_SOCKET`, `OPENNHRP_HA_SOCKET`, `OPENNHRPCTL_PATH`, and
`OPENNHRP_CONF_PATH`, and `OPENNHRP_HA_STATE_DIR`. `AUTH_TOKEN` and `AUTH_TOKEN_FILE` are accepted when
`TOKEN` is unset.

TLS certificate and hostname verification is always enabled for `wss://`.

### Spoke HA 质量状态

`opennhrp` 目标命令 `ha show format json` 的响应通过 `raw_text` 原样传输，包括
`quality_rtt_ms`、`quality_samples`、`quality_failures`、
`last_quality_reply_age_ms`、`quality_valid` 及三项评分；缺失测量保留 JSON `null`。
Agent 不计算评分或迁移等待状态。`loss_pct` 表示最近 30 秒已完成探测的失败率
（含超时和无效回复），`srtt_ms` 仍是超时估计，评分使用独立的 `quality_rtt_ms`。
`make test` 覆盖 32 个候选的大响应和空值透传。
